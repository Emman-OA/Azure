☁️ Azure Data Fundamentals (DP-900) Project | Data Technician Bootcamp
🚀 Project Overview
This project was completed as part of the Microsoft Azure Data Fundamentals (DP-900) training course during a Data Technician Bootcamp. The project focused on understanding core cloud computing concepts, exploring different types of data workloads, and gaining hands-on experience with Azure data services for relational, non-relational, and analytical data processing.

Through a combination of practical labs and data analysis exercises, I learned how modern organizations use cloud-based data platforms to store, process, analyze, and visualize data to support business decision-making. The project also included querying and analyzing datasets using SQL and exploring end-to-end data analytics solutions using Microsoft Fabric.
